uView Flutter

uView UI 组件库的 Flutter 社区复刻版：内置主题系统，50+ 基础组件，纯框架实现、零额外依赖。

浏览组件 GitHub 仓库

主题系统

UViewThemeData 提供 uView 默认蓝/成功/警告/错误/信息色、圆角、字号、间距 token，支持运行时 UView.update 切换。

零额外依赖

仅依赖 Flutter 框架与 cupertino_icons，全部组件纯框架实现，体积可控。

Dart 2.17 兼容

未使用 records / pattern 等 Dart 3 特性，对老项目友好。

配套 Demo

example/ 工程按 uView 分类提供可交互预览页，效果截图与用法示例一一对应。

快速安装

dependencies:
  uview_flutter:
    git:
      url: https://github.com/your-org/uview_flutter
      ref: main

快速开始

import 'package:flutter/material.dart';
import 'package:uview_flutter/uview_flutter.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) => UView(
    theme: const UViewThemeData(),
    child: MaterialApp(
      home: Scaffold(
        body: UCol(gap: 12, children: [
          const UText('欢迎使用 uview_flutter', bold: true, size: 18),
          const UButton(text: '主要按钮', type: UViewType.primary),
          UCell(title: '地址', value: '杭州', isLink: true),
        ]),
      ),
    ),
  );
}
